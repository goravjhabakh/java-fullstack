# Java Full-Stack Learning

A project-driven repository for learning professional Java backend and full-stack development.

The goal is to learn Java and Spring by building real applications rather than following long theory-first courses.

## Current focus

Backend development with:

- Java
- Spring Boot
- Maven
- REST APIs

Later:

- PostgreSQL
- Spring Data JPA
- validation
- Spring Security
- React + TypeScript
- Redis
- background processing
- Docker
- observability

## Learning approach

Work is split into small phases and specs.

Each spec follows:

1. Understand the problem
2. Learn the required concepts
3. Implement the feature manually
4. Review the implementation
5. Fix issues
6. Verify understanding
7. Commit
8. Move to the next spec

AI acts mainly as a mentor and reviewer, not an implementation agent.

## Repository structure

- `backend/` — Spring Boot application
- `docs/learning-plan.md` — overall roadmap
- `docs/progress.md` — completed work and current status
- `docs/architecture.md` — architecture decisions as the project grows
- `docs/specs/` — created later as each learning phase begins
